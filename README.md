# Superheroes App 🦸

An Android app that displays a scrollable list of superheroes,
built with Jetpack Compose as part of the Android Developer course (Unit 3).

## Features
- Scrollable list of heroes using LazyColumn
- Hero cards with name, description, and portrait image
- Material 3 design with top app bar
- Clean architecture with separated data and UI layers

## What I Learned
- Building layouts with Jetpack Compose
- Using LazyColumn for efficient list rendering
- Data modeling with Kotlin data classes
- Resource management with @StringRes and @DrawableRes
- Following single responsibility principle

## Tech Stack
- Kotlin
- Jetpack Compose
- Material Design 3
- Android Studio

## How to Run
1. Clone this repository
2. Open in Android Studio
3. Run on emulator or physical device (API 24+)
